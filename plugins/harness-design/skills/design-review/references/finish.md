# 마감 기준

화면이 "다 된 것처럼 보이는 것"과 "정말 다 된 것"의 차이를 메우는 목록이다. 무대 세트와 진짜 집의 차이와 같다. 앞면은 같아 보여도 문을 열어 보면 안다.
값(색·서체·간격)은 정하지 않는다. 값은 브리프와 토큰을 따른다.

ui-designer, design-polish 목업, landing-page 스킬이 만들 때 따르고, design-critic이 채점할 때 본다.

## 1. 콘텐츠

예시 콘텐츠도 실제 사용자가 있는 실제 제품에서 나온 것처럼 읽혀야 한다.

- **문구를 직접 쓴다.** lorem ipsum, "여기에 제목", "설명 텍스트" 금지. 제품의 말투로 실제 문장을 쓴다.
- **사람**: 후기·팀원은 제품의 대상과 지역에 맞는 구체적인 이름. 한 얼굴을 두 사람에게 쓰지 않는다.
- **브랜드·로고**: 그 업계에 있을 법한 이름을 지어낸다. 물류 도구의 고객은 물류 회사처럼 들려야 한다.
- **숫자**: 너무 둥근 숫자를 피한다. 가격은 실제 가격처럼, 지표는 소수점이나 끝자리가 홀수로, 목록의 날짜는 제각각.
- **금지 상투어**: 혁신적인, 획기적인, 차원이 다른, 완벽한 솔루션, 한 단계 업그레이드, 스마트한, 놀라운, 최고의
  (영문: revolutionize, supercharge, cutting edge, effortless, seamless, world class). 제품이 하는 일을 평범한 말로 쓴다.
- **문장 중간에 대시(-, –, —)를 쓰지 않는다.** 이어 붙이지 말고 문장을 나눈다.
- **영문 제목과 버튼은 문장형 대소문자**(Sentence case).
- **시스템 메시지**: 확인은 차분하고 구체적으로("김다은 님에게 청구서를 보냈습니다"). 오류는 무엇이 실패했고 다음에 뭘 하면 되는지
  ("업로드하지 못했습니다. 파일이 20MB를 넘습니다."). 감탄사와 느낌표는 쓰지 않는다.

## 2. 상태

상호작용하는 요소는 상태 전체를 갖춘다.

| 상태 | 기준 |
|---|---|
| hover | 배경 변화, 살짝 확대나 이동 |
| active | 누르는 느낌 (`scale(0.98)` 또는 `translateY(1px)`) |
| focus | 키보드 포커스가 보인다. 접근성 요건이라 생략 불가 |
| loading | 실제 배치 모양의 스켈레톤. 화면 가운데 빙글 도는 표시만 두지 않는다 |
| empty | 다음에 뭘 하면 되는지 알려주는 시작 화면. 빈 패널 금지 |
| error | 해당 위치에 구체적으로. `window.alert()` 금지 |

- 죽은 링크가 없다. `#`를 가리키는 버튼은 연결하거나 비활성으로 보이게 한다.
- 내비게이션에 현재 페이지가 표시된다.

## 3. 출시 전 (공개 페이지)

잊기 쉬워서 페이지를 미완성처럼 보이게 만드는 것들이다. capture.mjs의 `ship` 측정이 일부를 기계로 확인한다.

- 푸터에 개인정보 처리방침·이용약관 링크
- 브랜드에 맞춘 404 페이지
- 폼의 클라이언트 검증 (이메일 형식, 필수 항목)
- 키보드 사용자를 위한 "본문 바로가기" 링크
- 쿠키 동의 (해당 지역에서 필요하면)
- 파비콘
- `<html lang>`, `<title>`, meta description, `og:image` 등 공유 태그
- 의미 있는 이미지마다 alt
- 의미 있는 HTML: `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, 페이지당 `<h1>` 하나
- 모든 페이지에서 돌아갈 길

## 4. 만드는 솜씨

시각 값이 아니라 어떤 값을 쓰든 지키는 규칙이다.

- **겹친 모서리**: 둥근 면 안에 둥근 면이 있고 간격이 32px보다 작으면 `안쪽 반경 = 바깥 반경 − 간격`. 결과가 2px 이하면 안쪽은 각지게 둔다.
  예: 바깥 16px, 안쪽 여백 8px → 안쪽 8px. 동심원처럼 곡선이 나란히 흘러야 어색하지 않다.
- **줄바꿈**: 제목은 `text-wrap: balance`, 본문은 `text-wrap: pretty`로 마지막 줄에 단어 하나만 남지 않게 한다.
  한국어는 `word-break: keep-all`로 어절 중간에서 끊기지 않게 한다. 히어로 제목은 생각이 끊기는 지점에서 직접 줄을 나눈다.
- **움직임**: `transform`과 `opacity`만 움직인다 (`top`, `left`, `width`, `height` 금지). 브라우저 기본 곡선(`ease`, `linear`) 대신 토큰의 곡선을 쓴다.
  `prefers-reduced-motion`이면 이동을 빼고 투명도만 바꾼다.
- **스크롤 연출**: `IntersectionObserver`(또는 Framer Motion `whileInView`)로 한 번만 실행한다. 쓰로틀 없는 `scroll` 이벤트 리스너를 달지 않는다.
- **한국어 서체**: 영문 전용 서체(Geist, Manrope, Poppins 등)는 한글 글리프가 없어 시스템 서체로 떨어진다. 한국어 화면이면 한글을 포함한 서체를 토큰에 넣는다.
