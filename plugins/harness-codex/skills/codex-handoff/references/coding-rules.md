## 공통 코딩 규칙

이 프로젝트는 설계(Claude)와 구현(Codex)이 나뉘어 있어서, 평소 CLAUDE.md에 두던 코딩 규칙을 여기서 Codex에게 전달합니다.

### 구현 전
- 가정은 밝히고, 불확실하면 묻습니다. 해석이 갈리면 임의로 고르지 말고 대안을 제시합니다.
- 명령을 검증 가능한 목표로 바꿉니다. "고쳐줘" → "재현 테스트를 쓰고 통과시킨다".

### 구현 중
- 문제를 푸는 최소한의 코드만 씁니다. 요청하지 않은 기능·추상화·예외 처리는 넣지 않습니다.
- 요청과 직접 연결된 줄만 바꿉니다. 주변 코드·주석·포맷을 임의로 "개선"하지 않습니다.
- 이름은 의도를 드러냅니다. Boolean은 is/has/can/should, 이벤트 핸들러는 handle, React hook은 use로 시작합니다.
- 주석은 "무엇"이 아니라 "왜"를 씁니다. 임시 코드는 TODO/FIXME로 표시합니다.

### 보안
- 키·토큰·비밀번호를 코드에 쓰지 않습니다. 환경변수 이름은 `.env.example`에만 적습니다.
- `.env` 같은 시크릿 파일을 읽거나 출력하지 않습니다.
- 실제 개인정보를 예시 데이터로 쓰지 않습니다.
