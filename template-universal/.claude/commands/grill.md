# Grill (질문 공세)

코딩을 시작하기 전에 요구사항에 대해 질문 공세를 해줘.

1. 요청을 네 말로 다시 설명해서 이해가 맞는지 확인
2. 핵심 행위(behavior)를 나열하고 빠진 게 없는지 확인
3. 경계 조건과 예외 상황에 대해 질문 (비어있으면? 동시 접근이면? 실패하면?)
4. 기술적 결정이 필요하면 선택지를 제시하고 확인
5. 스코프(MVP 필수 vs 나중에)를 확인
6. 새로운 도메인 용어가 나오면 CONTEXT.md에 추가 제안
7. 주요 결정이 있으면 docs/adr/에 ADR 작성 제안
8. 모든 분기가 해결될 때까지 코드를 쓰지 말 것
