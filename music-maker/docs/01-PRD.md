## 1. 제품 비전 & 한 줄 정의

### 1.1 Elevator Pitch

> **"30초 만에 저작권 걱정 없는 BGM 한 곡. 텍스트만 쓰면, Mureka AI가 작곡·작사·보컬까지 끝냅니다."**
>
> Music Maker는 **YouTube 크리에이터, 팟캐스터, 인디 게임 개발자, 1인 마케터**를 위한
> **텍스트 기반 AI 음원 생성 SaaS**다. 사용자는 분위기·장르·길이만 입력하면
> 평균 45초 안에 보컬+반주가 포함된 완성형 트랙을 받아볼 수 있다.

### 1.2 제품 비전 (3년)

| 시점 | 비전 |
|---|---|
| **1년차 (2026)** | 1인 크리에이터를 위한 "캔바(Canva) of Music" 포지셔닝 확보 |
| **2년차 (2027)** | 스타일 학습 + 보컬 클로닝으로 "내 채널 전용 사운드" 시장 진입 |
| **3년차 (2028)** | 광고·게임·OTT 클라이언트를 위한 B2B API/라이선싱 플랫폼 확장 |

### 1.3 차별점 체크리스트

- [x] 가사 → 보컬 → 반주를 **단일 워크플로우**로 통합 (경쟁사: 분리된 도구)
- [x] **45초 P95** 생성 속도 (Suno/Udio 평균 60-90초 대비 우위)
- [x] **스템 분리 다운로드** 제공 → 영상 편집툴에서 재믹스 가능
- [x] **한국어 가사 자동 생성** 최적화 (Mureka API 강점 활용)
- [x] **사용량 기반 과금** (정액제 + 크레딧 하이브리드)

## 3. 핵심 기능 우선순위 (MoSCoW)

### 3.1 Must Have (MVP 필수)

- [x] **M1. 텍스트 → 음원 생성**: 프롬프트 + 장르 + 길이 입력 → Mureka `song.generate` 호출
- [x] **M2. 가사 자동 생성**: 한/영 토글, 주제 입력 → Mureka `lyrics.generate`
- [x] **M3. 미리듣기 (스트리밍 재생)**: 생성 완료 즉시 브라우저 재생 (waveform UI)
- [x] **M4. 다운로드**: MP3 320kbps / WAV 16bit 선택 다운로드
- [x] **M5. 사용자 인증 & 크레딧**: 이메일/Google OAuth + 크레딧 차감 로직

### 3.2 Should Have (Beta 단계)

- [ ] **S1. 스타일 프리셋**: Lo-fi, EDM, Cinematic, K-pop 등 10종 사전 정의 + 사용자 커스텀 저장
- [ ] **S2. 생성 이력 (History)**: 시간순/즐겨찾기/태그 필터, 재생성(Variation) 버튼
- [ ] **S3. 인스트루멘탈 분리**: Mureka `stem.separate` 활용, 보컬/드럼/베이스/멜로디 4트랙
- [ ] **S4. TTS 내레이션 트랙**: 광고/팟캐스트용 짧은 보이스오버 (Mureka TTS)

### 3.3 Could Have (v1.0~v1.5)

- [ ] **C1. 보컬 클로닝**: 사용자 음성 30초 업로드 → 본인 목소리로 가사 노래 (윤리 동의 필수)
- [ ] **C2. 프로젝트별 폴더**: 게임/채널/팟캐스트별 그룹화, 일괄 다운로드 (ZIP)
- [ ] **C3. 공유 링크**: 비로그인 미리듣기 가능한 short URL (워터마크 옵션)
- [ ] **C4. 배치 생성 (Bulk)**: CSV/프롬프트 리스트 업로드 → N곡 동시 생성
- [ ] **C5. 가사 편집기**: 생성된 가사 인라인 편집 → 재합성

### 3.4 Won't Have (v1 제외, v2 검토)

- [ ] ~~W1. 실시간 협업 편집 (Figma-style 멀티커서)~~ → 1인 사용자 중심이라 v1 제외
- [ ] ~~W2. DAW 수준 트랙 편집 (MIDI 노트 단위)~~ → DAW 시장 진입은 별도 전략
- [ ] ~~W3. 자체 음원 마켓플레이스 (사용자간 판매)~~ → 라이선스/세무 복잡, v2+
- [ ] ~~W4. 모바일 네이티브 앱~~ → v1은 반응형 웹으로 충분

### 3.5 MoSCoW 요약 매트릭스

| 우선순위 | 기능 수 | 누적 개발 주차 (FTE 2명 기준) | 출시 시점 |

## 6. 비기능 요구사항 (NFR)

### 6.1 성능 요구사항

| 항목 | 요구치 | 측정 방법 | 비고 |
|---|---|---|---|

| **평균 생성 시간 (P50)** | ≤ 45초 | Datadog APM | Mureka API + 우리 후처리 합계 |
| **P95 생성 시간** | ≤ 60초 | Datadog APM | |
| **최대 곡 길이** | 5분 (300초) | 입력 검증 (Zod) | Mureka API 제약 + 비용 관리 |
| **최소 곡 길이** | 15초 | 입력 검증 | 인트로/광고용 단편 지원 |
| **API 응답 시간 (생성 시작)** | P95 ≤ 500ms | Next.js Server Actions | 큐 적재까지의 시간 |
| **페이지 LCP** | ≤ 2.5초 | Lighthouse / CrUX | 메인 페이지 기준 |

### 6.2 가용성 & 신뢰성

| 항목 | 요구치 | 비고 |
|---|---|---|
| **SLA (월간 가동률)** | 99.5% (Beta) → 99.9% (v1.0) | Mureka API 다운타임 제외 |
| **데이터 보관** | 생성 음원 90일 (무료) / 무제한 (유료) | S3 Lifecycle Policy |

| **장애 복구** | Mureka API 장애 시 자동 재시도 (3회) + 큐 보존 | 사용자 크레딧 차감 보류 |
