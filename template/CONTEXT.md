# Domain Context

프로젝트 전체에서 사용하는 용어 사전. 모든 대화, 코드, 문서에서 이 용어를 일관되게 사용한다.
새로운 도메인 용어가 등장하면 여기에 추가하고, 모호한 표현은 정리한다.

## 용어 사전
